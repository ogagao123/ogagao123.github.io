中2社会 学習ナビ v0.5

v0.4からの主な強化
・学習アプリとしてのホーム画面を強化
・今日の5問を自動作成
・苦手度に応じた学習・出題
・間違い復習画面
・テストの制限時間（5/10/15分）
・テスト結果を正しく記録
・単元別理解度表示
・学習データのJSON書き出し/読み込み
・PWA用manifest / service worker
・スマホ向けレスポンシブUI

使い方
1. index.htmlをChrome/Edgeで開く
2. 「学習」でフラッシュカード
3. 「テスト」で中間・期末・苦手テスト
4. 「成績」で弱点と履歴を確認
5. 「範囲」で学校のテスト範囲を設定

注意
・学校ごとのテスト範囲は異なるため、範囲設定を利用してください。
・学習記録はブラウザのlocalStorageに保存されます。
・PWAのインストール/オフライン動作は、HTTPSまたはlocalhost等の環境で利用してください。
