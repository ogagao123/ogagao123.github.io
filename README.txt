中2社会 学習ナビ v0.6

【今回の主な変更】
・問題数を100問から300問へ増量（地理100・歴史115・公民85）
・基礎／標準／応用をバランスよく追加
・同じ知識を別角度から問う派生問題も追加
・テストの問題数に50問を追加
・問題バンク300問をホーム／学習／テスト／成績画面で確認可能
・v0.5 / v0.4の学習記録を引き継げるようにした
・JSONバックアップに問題数を記録

【使い方】
1. ZIPを展開
2. index.htmlをChromeまたはEdgeで開く
3. ホーム→今日の5問、学習、テストから利用

【学習のおすすめ】
まずフラッシュカードで覚える → 10問テスト → 間違い復習 → 苦手テスト、の順で使うと学習記録が活用されます。

【注意】
中2社会の学習範囲は学校・教科書・授業進度によって異なります。中間／期末の「範囲設定」で実際の学校の範囲に合わせてください。
