中2社会 学習ナビ v0.8（500問・学期別学習版）

主な更新
・問題数を300問から500問へ増量
・1学期 / 2学期 / 3学期 / すべて を選択可能
・選択した学期を、ホームの今日の学習、苦手学習、フラッシュカード、テストの出題条件に反映
・テスト問題数に100問を追加
・制限時間30分を追加
・v0.6以前の学習データを読み込めるように互換性を維持
・学習データは引き続きブラウザのlocalStorageに保存

学期の標準割当
1学期：日本の地域構成、人口、産業、地域調査、日本の諸地域
2学期：気候、自然災害、江戸時代、幕末
3学期：明治維新、公民各単元
※中学校によって進度は異なります。学期は出題フィルターとして利用してください。

使い方
1. index.htmlをChrome / Edgeで開く
2. ホームまたは学習・テスト画面で「学ぶ時期」を選ぶ
3. 学習→フラッシュカード→テスト→間違い復習を繰り返す

PWA
manifest.json と service-worker.js を同梱しています。Webサーバーへ配置すると、対応ブラウザでアプリとして追加できます。


学期について
「1学期」「2学期」「3学期」「すべて」を選択できます。学校ごとに進度が異なるため、学期は出題フィルターとして利用してください。


【v0.8 範囲修正】
・公民分野（憲法、国会、内閣、裁判所、地方自治、選挙など）を500問から削除。
・500問は地理200問＋歴史300問に再構成。
・中2定期テスト対策を想定し、歴史は近世～近代を中心に構成。
・1学期／2学期／3学期の学期フィルターを維持。学期の進度は学校ごとに異なるため、「すべて」も利用可能。
