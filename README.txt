中2社会 テスト前チェック v0.4

■ v0.4の主な更新
- 問題を100問に拡張（地理・歴史・公民）
- 問題データをapp.jsから独立したQUESTIONSデータとして冒頭にまとめ、今後増やしやすい構成
- 問題ごとに回答履歴、正答数、誤答数、連続正解数を保存
- 苦手度を自動計算
- 苦手克服モード
- 苦手問題を優先したテスト
- 単元別の正答率・苦手問題数
- テスト履歴
- 中間・期末テスト範囲をユーザーが自由に設定
- フラッシュカード学習
- 基礎・標準・応用・おまかせ
- 5/10/20/30問
- ブラウザのlocalStorageに学習記録を保存

■ 起動
index.htmlをChrome / Edgeなどで開いてください。

■ 注意
中間・期末の初期範囲は一般的な中2社会を想定したサンプルです。
実際の学校のテスト範囲は学校・教科書・進度によって異なるため、
「範囲設定」で変更してください。

- 問題画像・資料読み取り問題
- タイマー付き本番テスト
- 学習履歴グラフ
